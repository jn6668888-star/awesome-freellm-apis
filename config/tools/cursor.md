# Cursor 配置 — 免费 LLM API

## 设置步骤
1. 打开 Cursor Settings → Models
2. 点击 Add Model
3. 填入以下信息

## 推荐配置（免信用卡）

### Cloudflare Workers AI
- Model name: @cf/mistral/mistral-7b-instruct-v0.1
- Base URL: https://api.cloudflare.com/client/v4/accounts/{account_id}/ai/run
- API key: 从 https://dash.cloudflare.com/profile/api-tokens 获取

### Google Gemini
- Model name: gemini-3.6-flash
- Base URL: https://generativelanguage.googleapis.com/v1beta
- API key: 从 https://aistudio.google.com/app/apikey 获取

### GitHub Models
- Model name: Phi-4
- Base URL: https://models.github.ai/inference
- API key: 从 https://github.com/marketplace/models 获取

### LLM7.io
- Model name: deepseek-r1-0528
- Base URL: https://api.llm7.io/v1
- API key: 从 https://token.llm7.io 获取

### Groq
- Model name: moonshotai/kimi-k2-instruct
- Base URL: https://api.groq.com/openai/v1
- API key: 从 https://console.groq.com/keys 获取

### Mistral AI
- Model name: open-mistral-7b
- Base URL: https://api.mistral.ai/v1
- API key: 从 https://console.mistral.ai/api-keys 获取

### Cohere
- Model name: command-a-218b
- Base URL: https://api.cohere.com/v2
- API key: 从 https://dashboard.cohere.com/api-keys 获取

### Kilo Code
- Model name: nvidia/nemotron-3-ultra-550b-a55b:free
- Base URL: https://api.kilo.ai/api/gateway
- API key: 从 https://kilo.ai 获取
